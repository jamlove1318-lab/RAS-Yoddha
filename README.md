# RAS Yoddha | RPSC RAS Prelims Master & Gaming Arena 🏹

A high-performance, mobile-optimized **Progressive Web App (PWA)** hosted directly on **GitHub Pages** for the **RPSC Rajasthan Administrative Service (RAS) Preliminary Examination**.

🌐 **Live Web App**: [https://jamlove1318-lab.github.io/RAS-Yoddha/](https://jamlove1318-lab.github.io/RAS-Yoddha/)

---

## 🌟 Key Features

1. **📰 Daily Current Affairs (Auto-Updates Every Day)**:
   - Synchronized with the current date (`YYYY-MM-DD`).
   - 10-Question daily quiz rotating every midnight.
   - Rajasthan state welfare schemes, budget highlights, GI tags, solar policy, and appointments.
   - Daily news capsules for rapid revision.

2. **🚫 Zero Annoying Question Repetition**:
   - In-session tracking prevents questions from appearing twice in the same drill.
   - Standard questions solved correctly are marked mastered and **never repeat**.
   - **Only High-Importance Questions Repeat**: Spaced Repetition (SRS) schedule is reserved exclusively for high-yield questions ($\ge 90$ importance score) and previous mistakes.

3. **📝 Official Prelims Mock Simulator**:
   - Exact RPSC pattern: **150 Questions, 200 Marks, 180 Minutes**.
   - **$-1/3^{\text{rd}}$ ($-0.44$) Negative Marking** strictly calculated.
   - **Mandatory 5th Option Toggle** (*Option E: अनुत्तरित प्रश्न / Not Attempted* per latest RPSC rule).
   - Mobile-first slide-up Question Palette drawer.
   - Comprehensive solution key with bilingual (Hindi & English) analysis.

4. **📚 Unlimited Subject-Wise Questions**:
   - Covers all 11 RPSC Prelims subjects with procedural high-yield generators.
   - Instant solution feedback mode or exam drill mode.

5. **🎮 Gamified Learning Arena (4 Rounds)**:
   - **⚡ 60-Sec Rapid Fire Blitz**: Fast streaks with $4\times$ combo multiplier.
   - **👑 Kaun Banega RAS Officer**: 10 ranks from Patwari to SDM with 50:50, Poll & Skip lifelines.
   - **⚔️ Cutoff Boss Battle**: Defeat the 1000 HP Cutoff Demon with critical hits.
   - **🗺️ Rajasthan 7 Divisions Conquest**: Conquer Jaipur, Jodhpur, Udaipur, Kota, Bikaner, Ajmer, Bharatpur.

## 📱 How to Run on Any Mobile Device (No Login, Auto-Updating)

Anyone on any smartphone can open:
👉 **[https://jamlove1318-lab.github.io/RAS-Yoddha/](https://jamlove1318-lab.github.io/RAS-Yoddha/)**

### Install as an App on Mobile (PWA):
* **Android (Chrome)**:
  1. Open the link in Google Chrome.
  2. Tap the **three dots menu** (⋮) at the top right.
  3. Tap **"Install App"** or **"Add to Home screen"**.
* **iPhone / iPad (Safari)**:
  1. Open the link in Safari.
  2. Tap the **Share button** (square with arrow).
  3. Scroll down and tap **"Add to Home Screen"**.

### 🔄 Automatic Updates:
Because the app is served directly from GitHub Pages via a Service Worker, **whenever code is pushed to this repository, all devices will automatically receive the newest update on launch**. No APK download or manual update is required!
